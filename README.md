# 🎬 Movie Roulette

A Discord bot designed to help you and your friends decide what movie to watch!

Movie Roulette lets members of a Discord server build a shared movie collection and randomly select a movie when nobody can decide what to watch.

## 🚧 Project Status

Currently under development. The project is in its initial Java development phase.

## ✨ Planned Features

- **Movie Collection:** Add, remove, and list movies.
- **Duplicate Prevention:** Prevent movies with the same title from being added multiple times.
- **Random Selection:** Randomly pick a movie from the collection.
- **Watched Status:** Keep track of movies that have already been watched.
- **Server-Specific Collections:** Maintain a separate movie list for each Discord server.
- **Animated Roulette:** Display a spinning roulette animation before revealing the selected movie.
